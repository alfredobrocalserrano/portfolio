# Alfredo Brocal — Portfolio

Portfolio editorial de data scientist: proyectos de análisis de datos, IA y visualización con estética tipográfica editorial.

**Stack:** HTML · CSS · JavaScript vanilla · GSAP + ScrollTrigger (local, sin CDN en runtime)

**Estructura:**
- `index.html` — contenido (ES por defecto, EN vía toggle)
- `styles.css` — sistema de diseño papel/tinta
- `main.js` — animaciones, i18n, modal de proyectos
- `lib/` — GSAP y ScrollTrigger locales
- `assets/` — retrato, capturas reales de los proyectos y CV

**Ver en local:** abre `index.html` directamente en el navegador, o sirve la carpeta con `python -m http.server`.

**Deploy:** push a `main` → Vercel.
